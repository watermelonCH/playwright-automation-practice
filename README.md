# Playwright Automation Practice

## About This Project

This repository contains Playwright automation testing practice scripts written in TypeScript.

The test scripts are part of my learning journey in Playwright automation testing through Udemy.

## Test Scripts

| Test File | Description |
|---|---|
| `assignmentCheckpoint.spec.ts` | Assignment checkpoint automation tests |
| `refundEligibilityCheck.spec.ts` | Refund eligibility automation tests |

## Tech Stack

- Playwright
- TypeScript
- Node.js

## Installation

Clone the repository:

```bash
git clone https://github.com/watermelonCH/playwright-automation-practice.git
cd playwright-automation-practice
```

Install dependencies:

```bash
npm install
```

Install Playwright browsers:

```bash
npx playwright install
```

## Run Tests

Run all tests:

```bash
npx playwright test
```

Run a specific test file:

```bash
npx playwright test tests/assignmentCheckpoint.spec.ts
```

```bash
npx playwright test tests/refundEligibilityCheck.spec.ts
```
